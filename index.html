STUDENT QUICK START

How to run and explain this project

This new package runs as a single HTML website. It needs no Node.js, no login, no database, and no internet connection.

01

Open in Chrome

Extract the ZIP. Double-click open-in-chrome.bat. Chrome opens the 3D command center automatically.

02

Demonstrate Module 1

Open Scan, press Run scan simulation, and explain that -sV identifies services and versions only on approved assets.

03

Demonstrate Module 2

Select a training scenario, press Analyze, and explain the category, priority, confidence, and recommendation.

04

Demonstrate Module 3

Create a triage incident, then advance it through containment, validation, and closure.

Important ethical-hacking boundary

This demonstration intentionally performs no real port scan, exploitation, credential testing, surveillance, or hospital-network connection. In a real project, scanning requires explicit authorization and must target only approved assets. Never use real patient data.
